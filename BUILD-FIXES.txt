Kirikinux2 fixed source package

Included fixes:
- Marked scripts/linux/*.sh executable so GitHub Actions can invoke them.
- Updated Cocos2d-x UI setPosition calls for the current Vec2 API.
- Added the Linux XCB link dependency required by the standalone resource converter.

The third-party dependencies are intentionally omitted from this source package;
scripts/linux/fetch-thirdparty.sh downloads them during a normal build.

2026-10-07:
- psbfile.dll: PSBFile.load() dereferenced an unassigned PSBMedia pointer
  (SIGSEGV when psdlayer.tjs loads the first .pimg). See docs/psbfile-pimg-crash-fix.md.
- Storage: empty names are not locally accessible (saveSystemVariables failure).
- Linux fatal-signal reporter (crash.log), -g1 line tables, --build-id.
- scripts/linux/package-deb.sh; CI uploads only AppImage + deb on success,
  the whole job workspace on failure.
- GTK-backed `win32dialog.dll` compatibility for in-game font selection, with
  a headless-safe fallback when GTK/display support is unavailable.
- Windows-compatible localized font aliases, installed-font discovery, and
  language-aware `.ttc` face selection; focused FontNameTable tests.
- windowEx.dll: WindowEx left `ovbmp` (and other members) uninitialised;
  closing the window deleted a garbage pointer (SIGABRT, free(): invalid
  pointer).
- Native GTK font picker (system faces / font file / typed name) for
  Font.doUserSelect, win32dialog-based game font selectors and
  Preferences -> Default Font; added font files are remembered.
  See docs/font-picker-and-close-crash-fix.md.
